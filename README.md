# 🔐 Password Generator

A simple password generator built in Python. 🐍

The program allows the user to choose how many letters, symbols, and numbers they want in their password, then randomly generates and shuffles the characters.

## 🛠️ Built With

- 🐍 Python

## 🧠 Concepts Practiced

- 📋 Lists
- 🔄 `for` loops
- 🔢 `range()`
- 🎲 `random.choice()`
- 🔀 `random.shuffle()`
- ➕ `.append()`
- ⌨️ User input
- 🔢 Type conversion with `int()`
- 🔤 Strings
- 📦 Building a password from a list

## 🔑 How It Works

1. Choose how many letters you want.
2. Choose how many symbols you want.
3. Choose how many numbers you want.
4. The program randomly selects the requested characters.
5. The characters are shuffled into a random order.
6. The final password is displayed.
